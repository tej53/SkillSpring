Git HOL 5 - Step by Step

Step 1: Verify the Master Branch is Clean

Open Git Bash and go to your project:

    cd Desktop/GitDemo
    git checkout master
    git status

Make sure the output shows:

    nothing to commit, working tree clean

------------------------------------------------------------------------

Step 2: List All Available Branches

    git branch

To view local and remote branches:

    git branch -a

------------------------------------------------------------------------

Step 3: Pull the Remote Repository

Pull the latest changes from the remote repository:

    git pull origin master

  If your repository uses main instead of master, replace master with
  main.

------------------------------------------------------------------------

Step 4: Push Pending Changes

Push your local commits to the remote repository:

    git push origin master

If this is the first push:

    git push -u origin master

------------------------------------------------------------------------

Step 5: Verify the Changes on the Remote Repository

1.  Open your GitLab repository in your browser.
2.  Refresh the page.
3.  Verify that the latest commits and files are visible.

You can also verify from Git Bash:

    git log --oneline
    git remote -v
